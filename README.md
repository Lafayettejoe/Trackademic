# Trackademic

Know your numbers. Own your results.

A modern, Nigerian-context student grade tracker that calculates GPA, CGPA, and degree class using the NUC 5-point grading scale.

## Features

- Beautiful landing page with hero section and feature highlights
- Sign up / sign in with account creation
- Onboarding flow — select your Nigerian university from 100+ schools
- Choose your department from 70+ fields of study
- Dashboard with sidebar navigation (Overview, Courses, Settings)
- Overview page showing CGPA, semester GPA, degree class, and progress bar
- Add courses with score and credit units per semester
- Auto grade assignment (A–F) using NUC standard
- Live GPA and CGPA calculation
- Degree class indicator (First Class → Pass)
- Multi-semester tracking (100L to 400L, 8 semesters)
- Data saved locally in your browser
- Export/print your result summary

## Tech Stack

- Vanilla JavaScript (no framework)
- Plain CSS with CSS custom properties
- SVG inline icons
- localStorage for data persistence

## Getting Started

1. Open `index.html` in any modern browser
2. Click **Get Started Free** on the landing page
3. Create an account with your name and email
4. Select your university from the list
5. Select your department
6. Start tracking your courses and grades!
